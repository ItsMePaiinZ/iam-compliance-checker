# Control-Zuordnung (Schritt 4)

Hier kommt später `controls.yaml` hin: welche Prüfung zu welchem ISO-27001:2022-Control (Anhang A)
und zu welcher NIS2-Anforderung gehört.

Wichtig: Nur Control-Nummern und eigene Beschreibungen verwenden, keinen Normtext.
Die ISO-Normen sind urheberrechtlich geschützt.
